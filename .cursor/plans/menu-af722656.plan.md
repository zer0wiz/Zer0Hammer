# Menu.lua UIObjects 리팩터 계획

## 개요

기존 `menu.lua`의 혼재된 UI 로직을 공통 `UIObjects` 모듈로 분리하고, 메뉴 팝업을 해당 모듈 기반으로 재구성합니다.

## 단계

1. 현황 파악

- `TSpoons/AutoHotKeys.spoon/menu.lua`의 UI 관련 함수와 데이터 구조를 검토해 재사용/이관 대상 식별

2. UIObjects 설계

- `modules/UIObjects/elements` 하위에 정의: 레이어 테이블 레이아웃, 텍스트, 타이틀, 리스트, 구분선, 토글 요소 API 스펙 확정

3. UIObjects elements 구현 항목 
    1. 레이어 기본 틀(table 구조)
        1. table행렬[row,col, r-width, c-height] , 투명도, 배경색를 옵션으로 구현
        2. r-width와, c-height 는 기본 높이와 넓이이며, 생성후 개별 정의 가능하다.
ex) r-width[2].width = 10, c-height[1] = 20)
        3. element들을 배치할 수 있는 table을 정의한다. (row, col) {3,3}
        4. 레이어 내부에는 다른 레이어를 추가 배치하고 추가된 레이어에 element를 추가할 수 있다.
ex) menu.lua에서 a{3,3} 레이어를 생성하고, a[3,2] = b{1,2} 라고 정의한 다음 b[1,2] = text(...)으로 사용하여 삽입하는 방식.
        5. 레이어의 raw의 기본값은 미리 정의해두고, 입력
    2. text
        1. 텍스트, 폰트 크기, 글자색, 배경색
    3. title
        1. 2번 텍스트 element 객체, 타이틀 레이어 넓이, 정렬(레이어 왼쪽, 가운데, 오른쪽)
    4. 리스트
        1. 2번 텍스트 element의 리스트 객체, 넓이, 정렬
    5. 구분선
        1. 색상, 넓이 (메뉴 기본틀 기준으로 비율, 100=기본틀넓이, 50=기본틀 넓이의 절반), 정렬(왼쪽, 오른쪽, 가운데)
    6. 토글 버튼
        1. 크기, 색상, 유형(사각형, 원{현재 구현완료])

4. 메뉴 재구성

- `menu.create`, `menu.title` 등 메뉴 전용 API를 `UIObjects` 기반으로 재작성하고 기존 로직 치환

5. 검증 및 문서화

- 기존 동작과 시각적 동등성 확인, 필요 시 예제/주석 추가해 사용법 문서화
